# Security policy

## Supported code

Security fixes are applied to the current `main` branch. Older commits and forks are not maintained by this repository.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow for this repository: open the **Security** tab, choose **Advisories**, and create a private draft security advisory. Do not open a public issue for a suspected vulnerability.

Include, when relevant:

- the affected route, component, or commit;
- reproducible steps and expected impact;
- a minimal proof of concept that does not access or alter other people's data; and
- suggested mitigations, if known.

Do not include credentials, tokens, private keys, personal data, or live production records. If a secret may have been exposed, revoke or rotate it through the appropriate provider rather than posting it in the report.

This project does not advertise a bug bounty or a guaranteed response time. Please allow maintainers time to validate and coordinate a safe fix before public disclosure.
