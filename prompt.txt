## Core Product

ClassStatus NCR is a web application for students in **Metro Manila / NCR, Philippines** that quickly answers:

**“May pasok ba?”**

The application should show the current class suspension status of every NCR city/municipality through an interactive map.

Build the application using:

* **Next.js**
* **TypeScript**
* **Tailwind CSS**
* modern React patterns
* a clean project architecture
* responsive design

The final application should feel modern, fast, polished, trustworthy, and easy to understand.

Do not make it look like a generic admin dashboard.

## Automated Collector

Build a functional automated information collector.

The system should be able to collect class-suspension announcements from trusted public sources.

Potential authoritative sources include:

* Philippine government announcements
* DepEd
* CHED
* NCR LGU official pages
* official school/university announcements

It may also use reputable news organizations as secondary confirmation sources.

Design the collector so that sources can be added or removed cleanly.

The collector should:

1. retrieve new announcements
2. normalize the information
3. identify the LGU or institution
4. determine affected education levels
5. determine the effective date/time
6. identify whether the announcement is active or upcoming
7. extract the source URL
8. avoid duplicates
9. validate records
10. publish valid suspension data to the application

Do not blindly trust scraped text.

Build safeguards against incorrect or ambiguous announcements.

If information cannot be confidently interpreted, mark it appropriately instead of silently publishing incorrect information.

## Source Evidence

The system should prefer official sources over news reports whenever possible.

If multiple sources confirm the same suspension, combine or associate them instead of showing unnecessary duplicate records.
